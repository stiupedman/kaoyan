# 考研自律神器设计规格

## 1. 目标与边界

本项目是仅面向 Windows 的个人自律桌面程序。它让用户设置当日学习任务，通过全屏置顶的专注界面限制普通电脑使用；只有全部任务完成或使用当天的应急机会后，才能退出专注界面。

程序不接管 Windows 登录组件，也不声称提供系统级封锁。任务管理器、Ctrl+Alt+Delete、关机及管理员操作仍可能绕过限制。这是刻意保留的安全边界，避免程序故障导致用户无法使用电脑。

首版不包含账号、云同步、排行榜、历史统计、自动更新和多平台支持。

## 2. 技术方案

- 平台：Windows。
- 技术：C#、.NET、WPF。
- 进程：单个桌面程序，不安装后台服务或驱动。
- 存储：用户本地应用数据目录中的一个 JSON 文件。
- 网络：仅用于获取官方公布的下一次全国硕士研究生招生考试初试日期。
- 界面风格：清爽卡片式；浅色背景，倒计时为主页第一视觉层级。

## 3. 页面与组件

### 3.1 主页

主页在程序打开后立即显示：

- 距离下一次考研初试首日的剩余天数；
- 日期来源状态：官方获取、缓存或手动备用；
- 今日任务及其目标时长；
- 今日剩余应急解锁次数；
- “设置任务”“开始今日学习”或“返回学习”主按钮。

剩余天数按本地自然日计算：`考试首日日期 - 今天日期`。考试当天显示 0 天，日期已过时立即重新获取下一次考试日期。

### 3.2 任务设置页

每项任务只包含：

- 非空任务名称；
- 整数目标分钟数，最小 1 分钟。

至少创建一项任务才能开始学习。开始后，当日任务不能新增、删除、改名或缩短，避免从设置页绕过约束。

### 3.3 专注锁定页

锁定页使用无边框、全屏、始终置顶窗口，并阻止普通窗口关闭和 Alt+F4。页面始终显示考研倒计时、任务列表、当前任务计时、总体进度、剩余应急次数。

同一时间只允许一个任务计时。用户切换任务时暂停原任务并启动新任务。Windows 进入睡眠或应用退出时暂停计时，不把离线时间计入学习时长。

任务只有同时满足以下条件才完成：

1. 累计学习时间达到目标；
2. 用户手动点击确认完成。

所有任务完成后自动保存记录并退出锁定页。

## 4. 核心流程

1. 用户打开程序，主页立即显示考研倒计时。
2. 程序发现没有有效考试日期时，后台尝试从教育部官方页面获取；获取期间不阻塞任务设置。
3. 用户设置今日任务并点击“开始今日学习”。
4. 程序冻结任务清单、保存状态并进入专注锁定页。
5. 用户选择任务开始计时，逐项达到目标并手动确认。
6. 全部任务完成后解除锁定并回到完成状态主页。

程序意外退出后，再次启动时读取当日未完成状态并直接恢复锁定页。退出期间不补算学习时间。

## 5. 应急解锁

- 每个本地自然日最多使用两次。
- 点击应急解锁后必须进行二次确认，并明确显示使用后的剩余次数。
- 使用后立即暂停当前计时、保存状态并退出全屏锁定。
- 应急状态不设自动结束时间；用户再次进入程序并点击“返回学习”后恢复锁定。
- 应急解锁不完成、不删除也不缩短任务。
- 日期跨日时重置为两次机会。

若跨日时前一天任务仍未完成，程序归档前一天实际进度并回到主页，让用户设置新一天任务；不会把旧任务强制延续到新一天。

## 6. 考试日期获取

程序使用 .NET 自带 `HttpClient` 获取教育部官方“考试招生工作”信息，不接入第三方日期服务。解析目标是标题含“全国硕士研究生考试招生工作”的最新公告，并从正文中提取“初试时间”首日。

官方来源：

- [教育部考试招生工作栏目](https://www.moe.gov.cn/jyb_xwfb/gzdt_gzdt/s5987/)
- [2026 年公告示例](https://www.moe.gov.cn/jyb_xwfb/gzdt_gzdt/s5987/202509/t20250924_1414763.html)

每次启动最多请求一次，设置短超时。解析结果必须晚于或等于今天，过去届次的日期直接丢弃。获取成功后缓存日期和来源页面地址；失败时使用最近一次仍未过期的缓存。没有有效缓存时显示手动日期输入，手动日期必须晚于或等于今天。后续官方获取成功时替换手动备用日期，并在主页显示来源变化。

页面结构或公告措辞变化导致解析失败属于普通网络失败，不影响本地任务和锁定功能。

## 7. 本地状态

单个 JSON 文件保存：

- 当前日期；
- 考试日期、来源类型、来源地址和最后更新时间；
- 当日任务名称、目标秒数、累计秒数和确认状态；
- 当日是否已开始、是否处于应急状态；
- 当日已使用应急次数；
- 当前正在计时的任务标识。

状态每 5 秒以及每次关键操作后保存。保存采用同目录临时文件写入后替换，避免写入中断破坏原文件。

## 8. 异常处理

- 网络不可用：使用有效缓存或手动备用日期，不阻塞其他功能。
- 程序崩溃：最多丢失最后 5 秒进度；重启恢复锁定。
- 数据文件损坏：备份损坏文件并进入恢复页，不直接进入不可退出的锁定状态。
- 系统睡眠：暂停当前计时，恢复后由用户继续。
- 日期跨日：归档旧状态、重置应急次数并返回新一天主页。
- 系统时间被手动修改：活动计时使用单调时钟降低影响；自然日和倒计时仍以 Windows 本地日期为准。首版不加入联网校时或防篡改服务。

## 9. 验证

自动测试覆盖：

- 考试前、考试当天和考试后的倒计时边界；
- “计时达标 + 手动确认”的双重完成条件；
- 两次应急机会的消耗和跨日重置；
- 跨日任务归档；
- 崩溃恢复时不补算退出期间；
- 官方日期解析成功、失败和缓存回退；
- JSON 原子保存与损坏文件恢复。

人工验证一条完整流程：设置两项任务、开始锁定、切换计时、使用两次应急解锁、恢复锁定、完成全部任务、重启验证状态，并确认 Alt+F4 不能普通退出。

## 10. 完成标准

Windows 用户无需管理员权限即可运行程序；进入程序和锁定页均能看到考研倒计时；可以设置并冻结今日任务；计时达标且手动确认后才能正常解除锁定；每天恰有两次可持久化的应急解锁机会；崩溃、断网和数据损坏不会导致电脑被永久锁住。
